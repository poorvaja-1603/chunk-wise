## 1. Goal and scope

Goal: a local, single-process content-defined deduplication store that is correct, measurable, and honest about its limits. This plan implements the scope in the feasibility report (Section 4.1). The distributed design (conditional writes across two stores, resumable sessions, GC, recovery workers) is future work. Section 4 I2 gives the local analogue: one SQLite transaction covers refcount increments, the file record, and the manifest.

Acceptance criteria (from the feasibility report, Section 11.1):

- AC1: Adding identical input twice stores no new chunk bytes. The index records the extra references.
- AC2: Restored output is byte-for-byte identical to input.
- AC3: A small insertion into a large input keeps most chunk references (CDC), compared with whole-file hashing and fixed-size chunking.
- AC4: Tampered or missing chunks cause an explicit error on restore.
- AC5: Reports record parameters, dataset, baseline bytes, stored bytes, and dedup ratio. The benchmark output provides all of these.

## 2. Decisions

| Area | Decision | Reason |
|---|---|---|
| Language | Python 3.11+ | Team familiarity. Standard library is enough. |
| Chunking | Rabin-style polynomial rolling hash, modulus 2^61 - 1, base 257 | O(1) window slide. Matches the viva talking point. |
| Chunk sizes | min 2 KiB, avg 8 KiB, max 64 KiB, window 48 B | Feasibility report Section 4.3. |
| Avg size | Must be a power of two | Boundary test is `fp & (avg - 1) == 0`. |
| Chunk ID | SHA-256 hex | Collision-resistant. Stdlib. |
| Index | SQLite in WAL mode | ACID transactions. One file. No server. |
| Chunk store | Local filesystem, `objects/hh/rest` | Content-addressed. Atomic publish with `os.replace`. |
| File commit | One transaction for refcounts, file row, manifest | Atomic checkpoint (I2). |
| Concurrency | Single writer process | Writer coordination is out of scope. |
| Durability | `fsync` off by default, flag to enable | Speed. Limitation documented in section 14. |
| CLI | argparse | No dependency. |
| Tests | pytest | Standard. |
| Baseline chunker | Fixed-size, same avg size | Needed for AC3 and Figure 4. |

## 4. Invariants

- I1 (bytes before reference): a chunk's bytes are written to the store before any index row references its hash. Enforced in `Engine.put`.
- I2 (atomic file commit): the refcount increments, the file row, and all manifest rows commit in one transaction, or none do. Enforced in `Index.commit_file`.
- I3 (refcount meaning): `chunks.ref_count` equals the number of manifest entries that reference the chunk across committed files. No decrement exists in this scope.
- I4 (read correctness): `Engine.get` returns successfully only if every chunk matches its hash and length, and the whole file matches its size and SHA-256.
- I5 (accounting): `physical_bytes = sum(size of unique chunks)`, `logical_bytes = sum(file sizes)`, `dedup_ratio = logical / physical`, `storage_saved_pct = (1 - physical / logical) * 100`.
- I6 (chunker determinism): the same bytes and parameters give the same boundaries, regardless of how the stream is read.

Acceptable leftovers: if a process dies after I1 and before I2, the store has orphan chunk files that no index row references. They are harmless. Cleanup is out of scope.

### `src/chunkwise/chunker.py`

```python
"""Content-defined chunking (Rabin-style polynomial rolling hash) and fixed-size chunking.

Boundary rule: a cut is taken after byte i when
    chunk_len >= min_size and (fingerprint(window ending at i) & mask) == 0,
or unconditionally when chunk_len == max_size.
The rolling window is NOT reset at cut points, so boundaries depend only on
local content and re-synchronise after an edit.
"""
from __future__ import annotations

from dataclasses import dataclass
from typing import BinaryIO, Callable, Iterator

MOD = (1 << 61) - 1  # Mersenne prime 2^61 - 1
BASE = 257


@dataclass(frozen=True)
class ChunkParams:
    min_size: int = 2 * 1024
    avg_size: int = 8 * 1024
    max_size: int = 64 * 1024
    window: int = 48

    def __post_init__(self) -> None:
        if not (0 < self.min_size <= self.avg_size <= self.max_size):
            raise ValueError("require 0 < min_size <= avg_size <= max_size")
        if self.avg_size & (self.avg_size - 1):
            raise ValueError("avg_size must be a power of two")
        if self.window < 1:
            raise ValueError("window must be >= 1")

    @property
    def mask(self) -> int:
        return self.avg_size - 1


class RollingFingerprint:
    """Polynomial rolling hash over the last `window` bytes, modulo MOD.

    For k <= window bytes b_0..b_{k-1} (oldest first):
        fp = sum(b_j * BASE**(k-1-j)) mod MOD
    Sliding by one byte is O(1): subtract the outgoing term, multiply by BASE, add the incoming byte.
    """

    def __init__(self, window: int) -> None:
        self.window = window
        self._buf = bytearray(window)
        self._pos = 0
        self._filled = 0
        self._out_coef = pow(BASE, window - 1, MOD)
        self.fp = 0

    def push(self, byte: int) -> int:
        if self._filled == self.window:
            self.fp = (self.fp - self._buf[self._pos] * self._out_coef) % MOD
        else:
            self._filled += 1
        self.fp = (self.fp * BASE + byte) % MOD
        self._buf[self._pos] = byte
        self._pos = (self._pos + 1) % self.window
        return self.fp


def cdc_chunks(stream: BinaryIO, params: ChunkParams, read_size: int = 1 << 20) -> Iterator[bytes]:
    roll = RollingFingerprint(params.window)
    mask = params.mask
    chunk = bytearray()
    while True:
        block = stream.read(read_size)
        if not block:
            break
        for byte in block:
            fp = roll.push(byte)
            chunk.append(byte)
            n = len(chunk)
            if n >= params.max_size or (n >= params.min_size and (fp & mask) == 0):
                yield bytes(chunk)
                chunk = bytearray()
    if chunk:
        yield bytes(chunk)


def fixed_chunks(stream: BinaryIO, params: ChunkParams, read_size: int = 1 << 20) -> Iterator[bytes]:
    size = params.avg_size
    pending = bytearray()
    while True:
        block = stream.read(read_size)
        if not block:
            break
        pending += block
        while len(pending) >= size:
            yield bytes(pending[:size])
            del pending[:size]
    if pending:
        yield bytes(pending)


CHUNKERS: dict[str, Callable[..., Iterator[bytes]]] = {"cdc": cdc_chunks, "fixed": fixed_chunks}


def iter_chunks(stream: BinaryIO, method: str, params: ChunkParams) -> Iterator[bytes]:
    try:
        fn = CHUNKERS[method]
    except KeyError:
        raise ValueError(f"unknown chunker {method!r}") from None
    return fn(stream, params)
```

### `src/chunkwise/store.py`

```python
"""Content-addressed chunk bytes on the local filesystem.

Layout: <root>/objects/<first 2 hex>/<remaining hex>
Writes go to <root>/tmp and are moved into place with os.replace, so a reader
never observes a partial chunk. A digest always maps to the same bytes, so an
existing chunk is never rewritten.
"""
from __future__ import annotations

import os
import uuid
from pathlib import Path

from .errors import ChunkMissingError


class ChunkStore:
    def __init__(self, root: Path, fsync: bool = False) -> None:
        self.root = Path(root)
        self.fsync = fsync
        (self.root / "objects").mkdir(parents=True, exist_ok=True)
        (self.root / "tmp").mkdir(parents=True, exist_ok=True)

    def path_for(self, digest: str) -> Path:
        return self.root / "objects" / digest[:2] / digest[2:]

    def exists(self, digest: str) -> bool:
        return self.path_for(digest).exists()

    def put(self, digest: str, data: bytes) -> bool:
        """Store bytes under digest. Returns True if written, False if already present."""
        path = self.path_for(digest)
        if path.exists():
            return False
        path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.root / "tmp" / uuid.uuid4().hex
        with open(tmp, "wb") as f:
            f.write(data)
            f.flush()
            if self.fsync:
                os.fsync(f.fileno())
        os.replace(tmp, path)
        return True

    def get(self, digest: str) -> bytes:
        try:
            return self.path_for(digest).read_bytes()
        except FileNotFoundError:
            raise ChunkMissingError(f"chunk {digest} missing from store") from None
```

### `src/chunkwise/index.py`

```python
"""SQLite index: chunk refcounts, file records, ordered manifests.

All mutations of one file (chunk refcount increments, file row, manifest rows)
happen in ONE transaction. That makes the per-chunk increment and the manifest
checkpoint atomic locally, which removes the replay-double-count gap that the
distributed design has to solve with TransactWriteItems.
"""
from __future__ import annotations

import sqlite3
from contextlib import contextmanager
from dataclasses import dataclass
from pathlib import Path
from typing import Iterator, Sequence

from .errors import FileNotFoundInIndexError

SCHEMA = """
CREATE TABLE IF NOT EXISTS chunks (
    hash      TEXT PRIMARY KEY,
    size      INTEGER NOT NULL,
    ref_count INTEGER NOT NULL DEFAULT 0,
    status    TEXT NOT NULL DEFAULT 'committed'
);
CREATE TABLE IF NOT EXISTS files (
    file_id    TEXT PRIMARY KEY,
    name       TEXT NOT NULL,
    size       INTEGER NOT NULL,
    sha256     TEXT NOT NULL,
    chunker    TEXT NOT NULL,
    avg_size   INTEGER NOT NULL,
    created_at TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS manifest (
    file_id    TEXT NOT NULL,
    seq        INTEGER NOT NULL,
    chunk_hash TEXT NOT NULL,
    byte_offset INTEGER NOT NULL,
    length     INTEGER NOT NULL,
    PRIMARY KEY (file_id, seq)
);
"""


@dataclass(frozen=True)
class FileRow:
    file_id: str
    name: str
    size: int
    sha256: str
    chunker: str
    avg_size: int
    created_at: str


@dataclass(frozen=True)
class ManifestEntry:
    seq: int
    chunk_hash: str
    byte_offset: int
    length: int


class Index:
    def __init__(self, path: Path) -> None:
        self.conn = sqlite3.connect(str(path), isolation_level=None)  # manual transactions
        self.conn.execute("PRAGMA journal_mode=WAL")
        self.conn.executescript(SCHEMA)

    def close(self) -> None:
        self.conn.close()

    @contextmanager
    def _tx(self) -> Iterator[sqlite3.Connection]:
        self.conn.execute("BEGIN IMMEDIATE")
        try:
            yield self.conn
        except BaseException:
            self.conn.execute("ROLLBACK")
            raise
        else:
            self.conn.execute("COMMIT")

    def commit_file(
        self,
        row: FileRow,
        manifest: Sequence[tuple[int, str, int, int]],  # (seq, hash, byte_offset, length)
        refs: dict[str, int],   # hash -> number of references from this file
        sizes: dict[str, int],  # hash -> chunk size
    ) -> None:
        with self._tx() as c:
            c.executemany(
                "INSERT INTO chunks(hash, size, ref_count, status) VALUES (?, ?, ?, 'committed') "
                "ON CONFLICT(hash) DO UPDATE SET ref_count = ref_count + excluded.ref_count",
                [(h, sizes[h], refs[h]) for h in refs],
            )
            c.execute(
                "INSERT INTO files(file_id, name, size, sha256, chunker, avg_size, created_at) "
                "VALUES (?, ?, ?, ?, ?, ?, ?)",
                (row.file_id, row.name, row.size, row.sha256, row.chunker, row.avg_size, row.created_at),
            )
            c.executemany(
                "INSERT INTO manifest(file_id, seq, chunk_hash, byte_offset, length) VALUES (?, ?, ?, ?, ?)",
                [(row.file_id, seq, h, off, ln) for seq, h, off, ln in manifest],
            )

    def get_file(self, file_id: str) -> FileRow:
        r = self.conn.execute(
            "SELECT file_id, name, size, sha256, chunker, avg_size, created_at FROM files WHERE file_id = ?",
            (file_id,),
        ).fetchone()
        if r is None:
            raise FileNotFoundInIndexError(f"no file {file_id}")
        return FileRow(*r)

    def manifest(self, file_id: str) -> list[ManifestEntry]:
        rows = self.conn.execute(
            "SELECT seq, chunk_hash, byte_offset, length FROM manifest WHERE file_id = ? ORDER BY seq",
            (file_id,),
        ).fetchall()
        return [ManifestEntry(*r) for r in rows]

    def refcount(self, digest: str) -> int | None:
        r = self.conn.execute("SELECT ref_count FROM chunks WHERE hash = ?", (digest,)).fetchone()
        return None if r is None else r[0]

    def totals(self) -> tuple[int, int, int, int]:
        """Returns (logical_bytes, physical_bytes, file_count, unique_chunk_count)."""
        logical, nfiles = self.conn.execute("SELECT COALESCE(SUM(size), 0), COUNT(*) FROM files").fetchone()
        physical, nchunks = self.conn.execute("SELECT COALESCE(SUM(size), 0), COUNT(*) FROM chunks").fetchone()
        return logical, physical, nfiles, nchunks
```

### `src/chunkwise/engine.py`

```python
"""Write path (put), read path (get), verification, and accounting."""
from __future__ import annotations

import hashlib
import io
import uuid
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path
from typing import BinaryIO

from .chunker import ChunkParams, iter_chunks
from .errors import IntegrityError
from .index import FileRow, Index
from .store import ChunkStore


@dataclass(frozen=True)
class PutResult:
    file_id: str
    name: str
    size: int
    chunks: int
    new_chunks: int
    new_bytes: int
    chunker: str


@dataclass(frozen=True)
class Stats:
    logical_bytes: int
    physical_bytes: int
    dedup_ratio: float
    storage_saved_pct: float
    files: int
    unique_chunks: int


class _NullSink:
    def write(self, b: bytes) -> int:
        return len(b)


class Engine:
    def __init__(self, home: Path, params: ChunkParams | None = None, fsync: bool = False) -> None:
        self.home = Path(home)
        self.home.mkdir(parents=True, exist_ok=True)
        self.params = params or ChunkParams()
        self.store = ChunkStore(self.home / "chunks", fsync=fsync)
        self.index = Index(self.home / "index.sqlite3")

    def close(self) -> None:
        self.index.close()

    def __enter__(self) -> "Engine":
        return self

    def __exit__(self, *exc: object) -> None:
        self.close()

    # ---------- write path ----------
    def put(self, stream: BinaryIO, name: str, chunker: str = "cdc") -> PutResult:
        file_id = "f-" + uuid.uuid4().hex[:12]
        whole = hashlib.sha256()
        manifest: list[tuple[int, str, int, int]] = []
        refs: dict[str, int] = {}
        sizes: dict[str, int] = {}
        offset = 0
        new_chunks = 0
        new_bytes = 0

        for seq, data in enumerate(iter_chunks(stream, chunker, self.params)):
            digest = hashlib.sha256(data).hexdigest()
            whole.update(data)
            # Bytes are written BEFORE any index row references them (ordering invariant I1).
            if self.store.put(digest, data):
                new_chunks += 1
                new_bytes += len(data)
            manifest.append((seq, digest, offset, len(data)))
            refs[digest] = refs.get(digest, 0) + 1
            sizes[digest] = len(data)
            offset += len(data)

        row = FileRow(
            file_id=file_id,
            name=name,
            size=offset,
            sha256=whole.hexdigest(),
            chunker=chunker,
            avg_size=self.params.avg_size,
            created_at=datetime.now(timezone.utc).isoformat(),
        )
        self.index.commit_file(row, manifest, refs, sizes)  # single transaction (invariant I2)
        return PutResult(file_id, name, offset, len(manifest), new_chunks, new_bytes, chunker)

    def put_path(self, path: str | Path, chunker: str = "cdc") -> PutResult:
        p = Path(path)
        with open(p, "rb") as f:
            return self.put(f, p.name, chunker)

    def put_bytes(self, data: bytes, name: str, chunker: str = "cdc") -> PutResult:
        return self.put(io.BytesIO(data), name, chunker)

    # ---------- read path ----------
    def get(self, file_id: str, out: BinaryIO) -> int:
        """Stream the file into `out`. On error, the caller must discard `out`."""
        meta = self.index.get_file(file_id)
        whole = hashlib.sha256()
        total = 0
        for e in self.index.manifest(file_id):
            data = self.store.get(e.chunk_hash)  # raises ChunkMissingError
            if len(data) != e.length or hashlib.sha256(data).hexdigest() != e.chunk_hash:
                raise IntegrityError(f"chunk {e.chunk_hash} (seq {e.seq}) failed verification")
            out.write(data)
            whole.update(data)
            total += e.length
        if total != meta.size or whole.hexdigest() != meta.sha256:
            raise IntegrityError(f"file {file_id} failed whole-file checksum")
        return total

    def get_bytes(self, file_id: str) -> bytes:
        buf = io.BytesIO()
        self.get(file_id, buf)
        return buf.getvalue()

    def verify(self, file_id: str) -> int:
        return self.get(file_id, _NullSink())

    # ---------- accounting ----------
    def stats(self) -> Stats:
        logical, physical, nfiles, nchunks = self.index.totals()
        ratio = logical / physical if physical else 1.0
        saved = (1 - physical / logical) * 100 if logical else 0.0
        return Stats(logical, physical, ratio, saved, nfiles, nchunks)
```

### `src/chunkwise/cli.py`

```python
from __future__ import annotations

import argparse
import json
import os
import sys
from dataclasses import asdict
from pathlib import Path

from .engine import Engine
from .errors import ChunkWiseError, IntegrityError


def _home(arg: str | None) -> Path:
    return Path(arg or os.environ.get("CHUNKWISE_HOME", ".chunkwise"))


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(prog="chunkwise")
    ap.add_argument("--home", default=None, help="store directory (default $CHUNKWISE_HOME or ./.chunkwise)")
    sub = ap.add_subparsers(dest="cmd", required=True)

    p = sub.add_parser("put", help="store a file")
    p.add_argument("path")
    p.add_argument("--chunker", choices=["cdc", "fixed"], default="cdc")

    g = sub.add_parser("get", help="restore a file")
    g.add_argument("file_id")
    g.add_argument("-o", "--out", required=True)

    v = sub.add_parser("verify", help="re-hash every chunk of a file")
    v.add_argument("file_id")

    sub.add_parser("stats", help="print dedup accounting")

    args = ap.parse_args(argv)
    try:
        with Engine(_home(args.home)) as eng:
            if args.cmd == "put":
                print(json.dumps(asdict(eng.put_path(args.path, args.chunker)), indent=2))
            elif args.cmd == "get":
                out = Path(args.out)
                tmp = out.with_name(out.name + ".part")
                try:
                    with open(tmp, "wb") as f:
                        n = eng.get(args.file_id, f)
                except BaseException:
                    tmp.unlink(missing_ok=True)
                    raise
                os.replace(tmp, out)
                print(f"restored {n} bytes to {out}")
            elif args.cmd == "verify":
                print(f"ok: {eng.verify(args.file_id)} bytes verified")
            elif args.cmd == "stats":
                print(json.dumps(asdict(eng.stats()), indent=2))
    except IntegrityError as e:
        print(f"INTEGRITY ERROR: {e}", file=sys.stderr)
        return 2
    except (ChunkWiseError, FileNotFoundError) as e:
        print(f"ERROR: {e}", file=sys.stderr)
        return 1
    return 0
```

import hashlib
import io
import random

import pytest

from chunkwise.chunker import BASE, MOD, ChunkParams, RollingFingerprint, cdc_chunks, fixed_chunks

P = ChunkParams()  # min 2 KiB, avg 8 KiB, max 64 KiB, window 48


def _naive_fp(window_bytes: bytes) -> int:
    fp = 0
    for b in window_bytes:
        fp = (fp * BASE + b) % MOD
    return fp


def _digests(chunks):
    return [hashlib.sha256(c).hexdigest() for c in chunks]


def test_rolling_matches_naive_recompute():
    data = random.Random(0).randbytes(2000)
    roll = RollingFingerprint(48)
    for i, b in enumerate(data):
        fp = roll.push(b)
        assert fp == _naive_fp(data[max(0, i + 1 - 48): i + 1]), f"mismatch at byte {i}"


def test_cdc_roundtrip_and_size_bounds():
    data = random.Random(1).randbytes(1_000_000)
    chunks = list(cdc_chunks(io.BytesIO(data), P))
    assert b"".join(chunks) == data
    for c in chunks[:-1]:
        assert P.min_size <= len(c) <= P.max_size
    assert len(chunks[-1]) <= P.max_size


def test_cdc_is_deterministic():
    data = random.Random(2).randbytes(300_000)
    assert _digests(cdc_chunks(io.BytesIO(data), P)) == _digests(cdc_chunks(io.BytesIO(data), P))


def test_cdc_independent_of_read_size():
    data = random.Random(3).randbytes(200_000)
    whole = [len(c) for c in cdc_chunks(io.BytesIO(data), P, read_size=1 << 20)]
    small = [len(c) for c in cdc_chunks(io.BytesIO(data), P, read_size=777)]
    assert whole == small


def test_insertion_keeps_cdc_boundaries():
    data = random.Random(4).randbytes(1_000_000)
    before = set(_digests(cdc_chunks(io.BytesIO(data), P)))
    after = _digests(cdc_chunks(io.BytesIO(b"X" + data), P))
    shared = sum(d in before for d in after) / len(after)
    assert shared >= 0.9, f"only {shared:.2%} of chunks re-synchronised"


def test_insertion_breaks_fixed_chunks():
    data = random.Random(4).randbytes(1_000_000)
    before = set(_digests(fixed_chunks(io.BytesIO(data), P)))
    after = _digests(fixed_chunks(io.BytesIO(b"X" + data), P))
    shared = sum(d in before for d in after) / len(after)
    assert shared < 0.05


def test_fixed_roundtrip():
    data = random.Random(5).randbytes(100_001)
    assert b"".join(fixed_chunks(io.BytesIO(data), P)) == data


def test_params_validation():

```python
"""Deterministic synthetic datasets. Same seed -> same bytes, so runs are reproducible."""
from __future__ import annotations

import random

WORDS = (
    "lorem ipsum dolor sit amet consectetur adipiscing elit sed do eiusmod tempor "
    "incididunt ut labore et dolore magna aliqua enim minim veniam quis nostrud"
).split()


def random_bytes(size: int, seed: int) -> bytes:
    return random.Random(seed).randbytes(size)


def text_document(size: int, seed: int) -> bytes:
    rng = random.Random(seed)
    parts: list[str] = []
    n = 0
    while n < size:
        line = " ".join(rng.choice(WORDS) for _ in range(12)) + "\n"
        parts.append(line)
        n += len(line)
    return "".join(parts).encode("ascii")[:size]


def insert_at(data: bytes, pos: int, payload: bytes) -> bytes:
    return data[:pos] + payload + data[pos:]


def small_files(count: int, size: int, seed: int) -> list[tuple[str, bytes]]:
    rng = random.Random(seed)
    return [(f"f{i:05d}.bin", rng.randbytes(size)) for i in range(count)]
```

### `bench/run_bench.py`

```python
"""Runs every scenario with both chunkers and writes results/results.{json,csv}.

Usage:
    python bench/run_bench.py            # full run (about 5 to 10 min, pure Python)
    python bench/run_bench.py --quick    # 1/8 sizes, for a smoke test
"""
from __future__ import annotations

import argparse
import csv
import hashlib
import io
import json
import platform
import shutil
import sys
import tempfile
import time
from pathlib import Path

from datasets import insert_at, random_bytes, small_files, text_document

from chunkwise import ChunkParams, Engine

MiB = 1024 * 1024
ROOT = Path(__file__).resolve().parents[1]
OUT = ROOT / "results"


def scenarios(scale: int):
    def sz(mib: float) -> int:
        return int(mib * MiB / scale)

    d1 = random_bytes(sz(16), seed=1)
    base_text = text_document(sz(8), seed=2)
    base_bin = random_bytes(sz(8), seed=3)
    para = b"This paragraph was inserted to simulate an edit to the document. " * 20  # about 1.3 KB
    small = small_files(max(50, 2000 // scale), 4096, seed=5)

    yield "D1_random", [("d1.bin", d1)]
    yield "D2_duplicates", [(f"copy{i}.bin", base_bin) for i in range(4)]
    yield "D3_edited_text", [
        ("v1.txt", base_text),
        ("v2.txt", insert_at(base_text, len(base_text) // 2, para)),
    ]
    yield "D4_edited_binary", [
        ("v1.img", base_bin),
        ("v2.img", insert_at(base_bin, len(base_bin) // 4, random_bytes(4096, seed=9))),
    ]
    yield "D5_small_files", small + [(name + ".copy", data) for name, data in small]


def run_one(name: str, chunker: str, uploads) -> dict:
    home = Path(tempfile.mkdtemp(prefix="cw_bench_"))
    try:
        eng = Engine(home, ChunkParams())
        logical = 0
        put_s = 0.0
        ids, digests, per_put = [], [], []
        for fname, data in uploads:
            logical += len(data)
            t0 = time.perf_counter()
            res = eng.put_bytes(data, fname, chunker)
            dt = time.perf_counter() - t0
            put_s += dt
            ids.append(res.file_id)
            digests.append(hashlib.sha256(data).hexdigest())
            per_put.append({"name": fname, "chunks": res.chunks, "new_bytes": res.new_bytes, "seconds": round(dt, 3)})
        st = eng.stats()

        get_s = 0.0
        verified = True
        for fid, want in zip(ids, digests):
            buf = io.BytesIO()
            t0 = time.perf_counter()
            eng.get(fid, buf)
            get_s += time.perf_counter() - t0
            if hashlib.sha256(buf.getvalue()).hexdigest() != want:
                verified = False
        eng.close()

        mb = logical / MiB
        return {
            "scenario": name,
            "chunker": chunker,
            "files": len(uploads),
            "logical_bytes": logical,
            "physical_bytes": st.physical_bytes,
            "unique_chunks": st.unique_chunks,
            "dedup_ratio": round(st.dedup_ratio, 4),
            "storage_saved_pct": round(st.storage_saved_pct, 2),
            "put_seconds": round(put_s, 3),
            "put_s_per_mb": round(put_s / mb, 4) if mb else 0,
            "get_seconds": round(get_s, 3),
            "get_s_per_mb": round(get_s / mb, 4) if mb else 0,
            "verified": verified,
            "per_put": per_put,
        }
    finally:
        shutil.rmtree(home, ignore_errors=True)


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--quick", action="store_true")
    args = ap.parse_args()
    scale = 8 if args.quick else 1

    rows = []
    for name, uploads in scenarios(scale):
        for chunker in ("cdc", "fixed"):
            print(f"running {name} / {chunker} ...", flush=True)
            rows.append(run_one(name, chunker, uploads))

    OUT.mkdir(exist_ok=True)
    params = asdict_params(ChunkParams())
    meta = {"params": params, "quick": args.quick, "python": sys.version.split()[0], "platform": platform.platform()}
    (OUT / "results.json").write_text(json.dumps({"meta": meta, "rows": rows}, indent=2))
    flat = [{k: v for k, v in r.items() if k != "per_put"} for r in rows]
    with open(OUT / "results.csv", "w", newline="") as f:
        w = csv.DictWriter(f, fieldnames=list(flat[0].keys()))
        w.writeheader()
        w.writerows(flat)
    bad = [r for r in rows if not r["verified"]]
    print(f"wrote {OUT}/results.json and results.csv; unverified rows: {len(bad)}")
    return 1 if bad else 0


def asdict_params(p: ChunkParams) -> dict:
    return {"min_size": p.min_size, "avg_size": p.avg_size, "max_size": p.max_size, "window": p.window}


if __name__ == "__main__":
    raise SystemExit(main())
```

## 10. Benchmark method and reference results

Datasets (synthetic, seeded, deterministic):

- D1 random: 16 MiB random bytes (baseline; expected ratio 1.0)
- D2 duplicates: 8 MiB random bytes uploaded 4 times
- D3 edited text: 8 MiB generated text, then a version with a 1.3 KB paragraph inserted at the midpoint
- D4 edited binary: 8 MiB random bytes, then a version with 4 KiB inserted at 25%
- D5 small files: 2000 files of 4 KiB, then the same set again

Each dataset runs with `cdc` and `fixed`. Metrics: dedup ratio and storage saved (deterministic), and put and get seconds per MiB (machine-dependent).

Reference results (full run, Linux x86_64, Python 3.12.3, pure Python):

## 14. Known limitations (state these in the report)

- Single process, single writer. Crash behaviour is argued from the invariants (I1, I2) and is not fault-injected.
- `fsync` is off by default. After a power loss, a chunk file may be empty or missing while its index row survives. Reads catch this with the hash check and raise `IntegrityError`. Use `Engine(..., fsync=True)` when durability matters.
- The chunker is pure Python. It is slow on large inputs, so benchmark sizes are small.
- No delete or GC. `ref_count` only increases.
- Timings are for this prototype on one machine, not production numbers.
